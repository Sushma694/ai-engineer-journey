# Day - 04 Homework

## What does git status do?
    git status checks the changes done in the project.

## Why do we use git add?
    We use git add to stages the changes done in the project.

## What does git commit do?
    git commit helps to save the changes.

## Difference between git push and git pull?
    git push : push the changes to Git Hub.
    git pull : pull the changes from Git Hub to local computer.

## What does git diff show?
   shows the changes between versions/state

## Why do we use Git branches?
    we use branches to develop something without impacting the main project, later we can merge it with the main.

## What does git merge do?
    git merge helps to merge the branch and main

## Explain this workflow: Branch → Make changes → Add → Commit → Merge → Push
    will create the branch and will do some changes or data, will stage the changes using add and save the changes and merge it with the main and push to Git Hub
