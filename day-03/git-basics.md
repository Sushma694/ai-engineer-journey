# Day 3 — Command Line & Git Basics

## Command Line

The Command Line is a text-based way to interact with a computer by typing commands.

### Commands learned

pwd → shows the current folder path

dir → lists files and folders in the current directory

mkdir → creates a new folder

## Git

Git tracks changes in a project.

GitHub stores Git repositories online.

Staging selects changes for the next commit.

Commit saves a snapshot of the staged changes.
