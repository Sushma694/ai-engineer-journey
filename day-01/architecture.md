# Day 1 — Developer Fundamentals

## Frontend vs Backend

Frontend is the part of an application that the user interacts with.

Backend is the part that handles application logic, processing, and communication with other services.

## API

An API is a defined way for two software systems to communicate with each other.

## Server

A server is a computer or system that receives requests and provides services or data.

## Database

A database is used to store and manage data.

## AI Application Flow

User → Frontend → Backend/API → AI Model → Response → User

Optional:
Backend → Database
Backend → External APIs
Backend → RAG / Tools
