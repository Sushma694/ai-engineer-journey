# Day 2 — Internet & HTTP

## Internet
The Internet is a global network that connects devices so they can communicate and exchange data.

## IP Address
An IP address identifies a device on a network so data can reach the correct destination.

## DNS
DNS translates a human-readable domain name into an IP address.

Example:
google.com → DNS → IP address

## HTTP
HTTP (HyperText Transfer Protocol) is a protocol used for communication between a client and a server.

## HTTPS
HTTPS is HTTP secured with TLS encryption.

S = Secure

## URL
A URL identifies how and where to access a resource.

Example:
https://www.google.com/search?q=AI

- https → protocol
- www.google.com → domain/host
- /search → path
- q=AI → query parameter

## HTTP Request
A message sent by a client to a server asking for a resource or action.

## HTTP Response
A message sent by the server back to the client after processing a request.

## HTTP Methods

GET → retrieve data
POST → send data to the server

## HTTP Status Codes

200 → OK / Success
201 → Created
400 → Bad Request
404 → Not Found
500 → Internal Server Error

## Basic Flow

You → DNS → IP → HTTPS → HTTP Request → Server → HTTP Response → You
